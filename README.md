# Abdullah Al Royhan - Personal Website

## GitHub Pages
1. Create a GitHub repository named `YOURUSERNAME.github.io`.
2. Upload `index.html`, `style.css`, and `profile.jpg`.
3. Go to Settings → Pages.
4. Select `Deploy from a branch`, branch `main`, folder `/ (root)`.
5. Save. Your site will appear at `https://YOURUSERNAME.github.io`.

You can later ask ChatGPT to change the name, bio, colors, buttons, sections, or design.
